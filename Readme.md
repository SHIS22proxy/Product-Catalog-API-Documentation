# 🛍️ Product Catalog API

A simple API to manage your product list — add, update, view, or delete products easily.

## 🔧 What You Can Do
- Create new products  
- Get a list of products  
- Update product details  
- Delete a product  

## 📌 Sample Product
```json
{
  "name": "Wireless Mouse",
  "sku": "WM123",
  "price": 29.99,
  "category": "Accessories",
  "in_stock": true
}
```

## Auth Example
```
Authorization: Bearer <your-token>

```

## Sample Call (cURL)
```
curl -H "Authorization: Bearer <token>" https://api.example.com/v1/products

```
